DropChat

A chat room and a file drop that lives on your Wi-Fi. No account. No internet. Just your network.

Run one Python file on one machine. Everyone else on the same Wi-Fi opens the address it prints — and they're in.

THE SERVER PRINTS ITS OWN URL · PASSWORD-GATED MODE · FILE CAP 100 MB BY DEFAULT · ZERO INSTALL

▸ WHAT IT DOES

REAL-TIME CHAT

Names, message history, live updates. Every client in the room sees messages the moment they're sent.

DRAG & DROP FILES

Drop a file into the page and it lands in the shared upload folder for everyone to grab. No services in between.

FINDS OTHER DROPS

Servers announce themselves over the network. One click lists every DropChat running on your Wi-Fi.

WHO'S ON MY WI-FI

Scans the ARP table and labels every device — your phone, the router, that TV, everything.

OPTIONAL PASSWORD

Lock the room with a key. The link becomes http://host:8000/?key=… — nobody in, nobody guessing.

ONE FILE, ZERO INSTALL

The whole server is a single Python script. Copy it to a machine, run it, done.

▸ THE SERVER SAYS

Run it once and it tells the room where it lives.

$ python server.py --name "The Living Room"
DropChat is running!
  On this PC:     http://localhost:8000
  On your Wi-Fi:  http://192.168.1.5:8000
  Press Ctrl+C to stop.
$ python server.py --name "The Living Room" --pass s0me-key
DropChat is running!
  On this PC:     http://localhost:8000
  On your Wi-Fi:  http://192.168.1.5:8000
  Password:       s0me-key
  Add ?key=s0me-key to every address above
  Press Ctrl+C to stop.

Everyone on the Wi-Fi opens the same address in a browser. No app to install on their side either.

▸ FLAGS

It listens politely, but it also takes orders.

--port8000HTTP port to serve on
--nameDropChatserver name shown to other DropChats
--passnonerequire ?key=… on every request
--max-mb100upload size cap per file

▸ RUN IT

Needs Python 3 and nothing else — it uses only the standard library.

python server.py

Windows just double-clicking start.bat works too — it launches the server named after your PC.
